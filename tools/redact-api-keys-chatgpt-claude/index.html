Frequently Asked Questions

How can I verify PromptShield sends zero data over the internet?

Open Chrome DevTools -> Network tab, paste sample secrets, click Mask, and observe zero outbound requests. It works identically with Airplane Mode on.

Does it destroy .env variable names?

No. PromptShield masks only the secret value while preserving keys like DATABASE_URL= and OPENAI_API_KEY= so the LLM understands your config structure.

Where is the reversible token vault stored?

Only in local browser session memory — never synced to any remote server.

Frequently Asked Questions

Which math rendering engines are supported?

KaTeX (`annotation[encoding='application/x-tex']`), MathJax v2/v3 (`mjx-container`, `script[type='math/tex']`), arXiv HTML5 (`LaTeXML`), Wikipedia math SVGs, and Zhihu math blocks.

Why include an LLM token counter?

So you can immediately see whether a clipped arXiv paper or documentation page fits cleanly inside a Claude, ChatGPT, or Gemini prompt window.

Does CleanClip MD require an external subscription for summarization?

No. Single-tab clipping is free, and optional Pro AI tagging/summarization is 100% BYOK (bring your own OpenAI-compatible or Gemini API key) stored locally.

How does multi-tab export work?

In CleanClip MD Pro ($12 one-time), select any set of open research tabs and export all cleaned Markdown notes plus an auto-linked `_INDEX.md` inside one ZIP.

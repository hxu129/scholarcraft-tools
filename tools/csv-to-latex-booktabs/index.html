Frequently Asked Questions

No. All CSV parsing, column ranking, and booktabs generation run strictly inside your browser with zero backend uploads.

TableForge emits \sisetup{detect-weight=true} compatible markup so bold best values and underlined second-best values stay aligned on the decimal point.

Frequently Asked Questions

Is the SHA-256 fingerprint verifiable later?

Yes — anyone running `shasum -a 256 deidentified.csv` gets the exact hash printed on the IRB certificate.

Does the certificate replace institutional legal review?

No — SafeHarbor Studio is a technical de-identification and audit-logging tool; investigators must still confirm the HIPAA 'no actual knowledge' prong and follow local IRB policies.

Can I export the shareable bundle without accidentally attaching the Re-ID key map?

Yes. The shareable ZIP package explicitly excludes `reid_key_map_DO_NOT_SHARE.csv` by default so the linking table stays strictly in the PI's separate vault.

Can our lab automate this across 50 CSV exports?

Yes — Pro includes `cli/safeharbor.py`, a zero-dependency Python 3 CLI with bit-for-bit parity with the browser engine.

Frequently Asked Questions

Why are these 17 specific 3-digit ZIP prefixes restricted under HIPAA?

Under 45 CFR § 164.514(b)(2)(i)(B), retaining the first 3 digits of a ZIP code is only permitted when the combined geographic unit has more than 20,000 inhabitants based on Census data; those 17 prefixes fall at or below 20,000 and must be changed to 000.

What happens to ZIP+4 codes like 94107-1234?

SafeHarbor Studio extracts the 5-digit core, validates the 3-digit prefix (`941`, >20,000 population), and outputs `941`.

Can I run this on an air-gapped hospital workstation?

Yes — both the standalone offline HTML app and the zero-dependency Python CLI require zero internet connection.

Does it also scrub free-text notes?

Yes, inline phone numbers, emails, SSNs, full dates, URLs, IPs, and Dr./Mr./Ms. names inside note columns are automatically redacted.
